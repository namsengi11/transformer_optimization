# Continuous-agent results

Only results produced by the workflow in `agent/ORCHESTRATOR.md` belong here. Historical
benchmark outputs from the previous workflow remain in the repository root (`results/` and
the root result text files) and must not be silently imported as fresh agent evidence.

- `_artifacts/`: machine-local profiler and scaffold verification captures.
- `digests/`: periodic summaries and dashboard data.
- Other subdirectories may be created for named agent runs.

Machine-local JSON, SQLite, and Nsight files are ignored by Git. Concise Markdown or text
summaries may be tracked when they cite exact provenance.
